## 四条 ADR 一句话

| ADR | 决策 | 不这么做的代价 |
|---|---|---|
| 001 | 契约号独立于三仓发版 | 兄弟仓发版把本仓拖下水；接缝静默漂移、运行期才炸 |
| 002 | 跨仓 import 只准出现在 `bridges/` | 三仓从「可独立发布」退化成「一损俱损」 |
| 003 | 文件契约与服务契约并存、不互相替代 | 要么失去离线 / 跨进程能力，要么失去热重载与实现替换 |
| 004 | 依赖清单只有一份，pyglet 跟 3dworld 精确锁版 | 两份清单漂移、干净机按文档装完跑不起来；两仓解析出不同 pyglet 版本 |

## 与代码层的对应

```
contracts/            ← ADR-001（版本）+ ADR-003（两条正交轴）
bridges/              ← ADR-002（唯一进口）+ ADR-004（传递依赖的来处）
pyproject.toml        ← ADR-004（唯一依赖清单）
requirements.txt      ← ADR-004（-e . 转发）
scripts/bootstrap.py  ← ADR-004（依赖自检）+ 架构总览「干净机复现」
assembly.py           ← 架构总览「三道装配门禁」
_locate.py            ← 架构总览「路径解析」（唯一处理路径的地方）
live.py / devloop.py  ← ADR-003（服务契约支撑 M3 / M4）
```

## 维护纪律

- 改装配 / 桥接结构 ⇒ 先看这里有没有对应 ADR；**新决策新开一条 ADR**，别把旧 ADR 改得面目全非。
- 代码注释引用文档必须指向仓内真实路径，不写「见规划文档 §x.y」——
  3 处历史悬空引用的处置记录见 [`../design/悬空引用处置.md`](../design/悬空引用处置.md)。
- 风险台账里带日期的结论是**时点事实**（尤其本机→GitHub 直连可用性），复核后回写，别当恒定结论。
- 路径一律**去盘符**（工作区 `SPEC-006`）：写 `3dworld/...` 或 `/repos/...`，不写「盘符 + 绝对路径」形式。
